# Симулятор энергосети

## Запуск
### Запуск в консольном режиме
Тест с избытком генерации (brute force)
```
python simulator.py tests/test_surplus.json
```
Тест с дефицитом генерации (brute force)
```
python simulator.py tests/test_deficit.json
```
С DP алгоритмом
```
python simulator.py tests/test_surplus.json --method dp
python simulator.py tests/test_deficit.json --method dp
```
### Запуск с интерфейсом и генератором тестов
Создать и активировать окружение
```
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Mac/Linux
```
Установить зависимости
```
pip install -r requirements.txt
```
Запуск streamlit
```
streamlit run app.py
```

## Зависимости
```
python3.14.3
```
Для версии с интерфейсом/генератором тестов все зависимости находятся в `requirements.txt`

## Описание решения
Симулятор разбивает общую задачу по распределению работы генераторов за день на подзадачи по выбору оптимального набора генераторов для максимально возможного числа потребителей в конкретные часы.  
<br> 
При выборе потребителей используется жадный алгоритм - выбираются потребители с наименьшим потреблением до тех пор, пока суммарный запрос не превысит максимально возможную отдачу всех генераторов в этот час.   
<br>
При выборе генераторов способом полного перебора ('brute'), перебираются все возможные подмножества генераторов, и выбирается подмножество с наименьшей ценой и достаточной отдачей энергии.   
<br>
При выборе генераторов методом динамического программирования ('dp') используется подход, 
аналогичный задаче о рюкзаке: строится таблица минимальных стоимостей для каждого возможного 
объёма выдачи энергии. Поскольку мощности генераторов могут быть дробными, значения 
масштабируются умножением на 10 для перевода в целые числа. Метод работает эффективнее 
полного перебора при большом числе генераторов — O(n * W) против O(2^n), где n — число 
генераторов, W — максимальная суммарная мощность.

## Допущения и упрощения
При решении задачи не учитывается приоритет потребителей - потребители выбираются от наименьшего потребления к наибольшему.   
Задача решается с предположением, что генераторы нельзя включить частично   
При решении задачи все часы считаются независимыми друг от друга   
Не учитывается стоимость запуска и остановки генератора — предполагается что 
включение/выключение бесплатно.

## Возможные расширения
- Поддержка накопителей энергии (батарей) — хранение излишков для использования в часы дефицита
- Учёт стоимости запуска генератора
- Приоритеты потребителей (критические объекты получают энергию первыми)
- Частичная нагрузка генераторов с решением через линейное программирование
